# Lab 1: Pizza Order Calculator

Course: TMA3084 SE LAB

## Description
This is a Dart program that calculates the total payment for pizza orders.

## Pizza Prices
- Small Pizza : USD 5
- Medium Pizza : USD 7 
- Large Pizza : USD 10

## Features
- Allows users to select a pizza size.
- Allows users to enter pizza quantity.
- Calculates total payment using a switch statement.
- Uses a while loop for continuous ordering.

## Programming Language
Dart

## How to run
1. Open the program in VS code.
2. Open the terminal.
3. Type: dart run main.dart
4. Follow the instructions displayed.
